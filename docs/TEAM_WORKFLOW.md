# Team workflow
- `main`: stable demo.
- `develop`: integration branch.
- `feature/tv1-trocr`: TrOCR.
- `feature/tv2-data-detection`: data/detection.
- `feature/tv3-correction-app`: correction/app.

Create feature branch from develop → commit → push → open PR to develop → review → merge. Do not commit raw private documents, datasets, secrets, or model checkpoints.

Milestones: 16/11 initial report; 27/11 demo; 15/12 final.
